# espresso

gtk 2/3/4 theme and symbolic icon set built from the frappe espresso design tokens.
made for [obwl-de](https://github.com/primalkz/obwl-de) but works on any desktop.

```sh
cp -r themes/* ~/.local/share/themes/
cp -r icons/* ~/.local/share/icons/
```

then pick Espresso as the gtk and icon theme. theme docs are in themes/Espresso/README.md.
